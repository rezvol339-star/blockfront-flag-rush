# Blockfront Flag Rush

Create a fully playable 2D/3D browser multiplayer-style mini-game inspired by "Flag Wars" and Blockman GO.

Core Mechanics & Features:

Teams: Two teams, Red and Blue, fighting against each other on a map with a dividing line.

Resource Generation (Gold/Blocks): There are resource spawn zones on the map where players can collect gold and materials over time.

Combat & PvP: Players can fight each other using melee weapons (swords) and basic combat mechanics to eliminate opponents and defend their base.

Flag Capture: Each team has a base with a flag. The objective is to infiltrate the enemy base, grab their flag, and bring it back to your base to score points.

Upgrades / Shop: Use collected gold to buy better weapons, armor, or defensive blocks.

UI & Controls: Clear controls (WASD to move, Mouse to aim/attack/interact), health bars for players, a score tracker for both teams, and a smooth restart loop when a round ends.

Make the gameplay addictive, fast-paced, and optimized for a smooth browser experience.
